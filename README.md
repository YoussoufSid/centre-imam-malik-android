# تطبيق مركز الإمام مالك

تطبيق Android أصلي لإدارة الطلاب والحضور ومتابعة حفظ القرآن الكريم.

## التشغيل

1. افتح المجلد في Android Studio.
2. انتظر اكتمال Gradle Sync.
3. شغّل التطبيق على هاتف Android أو محاكي.
4. أنشئ حساب الإدارة من شاشة «إنشاء حساب» بالبريد `sidibey487@gmail.com`.

يعمل Firestore بذاكرة محلية افتراضيًا؛ تُحفظ التغييرات عند انقطاع الإنترنت وتتم مزامنتها عند عودته.

## الصلاحيات

- الإدارة: كامل الصلاحيات.
- المعلم: إضافة الطلاب وتسجيل الحضور والحفظ.
- ولي الأمر والطالب: الاطلاع (بعد ربط الحساب بالطالب في مرحلة الإدارة).

قبل الاستخدام الفعلي، انشر ملف `firestore.rules` في Firebase Console.
