# تطبيق مركز الإمام مالك لتحفيظ القرآن الكريم والدراسات الإسلامية

تطبيق Android أصلي (Kotlin + Jetpack Compose + Firebase) لإدارة الطلاب والحضور ومتابعة حفظ القرآن الكريم ومراجعته.

## المزايا

- **الرئيسية**: ملخص اليوم (الطلاب النشطون، الحاضرون، الغائبون، عدد جلسات التسميع) وتنبيه بالطلاب غير المسجَّل حضورهم.
- **الطلاب**: ملف كامل لكل طالب، بحث بالاسم أو الهاتف، وتصفية حسب الحلقة.
- **ملف الطالب**: البيانات الشخصية، الاتصال بولي الأمر مباشرة، نسبة الحضور، عدد السور المحفوظة، وسجل الحفظ والحضور.
- **الحضور**: حاضر / متأخر / غائب / معذور، التنقل بين الأيام، وتسجيل حضور الجميع بضغطة واحدة.
- **الحفظ**: تسجيل الحفظ الجديد والمراجعة (السورة من قائمة السور الـ114، من آية إلى آية، التقدير، ملاحظات المعلم).
- **التقدم بالأحزاب**: شريط تقدم لكل طالب (من 60 حزبًا) يحدّثه المعلم، وقائمة «الأكثر حفظًا» في الرئيسية.
- **التقرير الشهري**: تقرير لكل طالب (الحضور، الحفظ، المراجعة، ملاحظات المعلم) يُرسل لولي الأمر عبر واتساب أو يُشارك بأي تطبيق.
- **الدراسات الإسلامية**: درجات من 20 في القرآن والتجويد، الفقه، العقيدة، الحديث، السيرة النبوية، اللغة العربية، والأخلاق؛ إدخال سريع لدرجات حلقة كاملة، ومعدل وتقدير لكل طالب ولكل فصل، وتُضاف إلى التقرير الشهري.
- **التاريخ الهجري** في الصفحة الرئيسية (تقويم أم القرى).
- **الإعلانات**: تنشر الإدارة إعلانات (عطل، مسابقات، اجتماعات) تظهر في الرئيسية للجميع أو لأولياء الأمور أو للمعلمين.
- **المالية** (للإدارة): أربعة أقسام:
  - **الشهرية**: الرسوم الشهرية لكل طالب، تسجيل الدفع، المحصَّل والمتوقع، ومن لم يدفع مع تذكير واتساب.
  - **التسجيل**: رسوم التسجيل (مرة واحدة) لكل طالب، المحصَّل والمتبقي.
  - **المصروفات**: رواتب، إيجار، كهرباء وماء، مصاحف وكتب... مع المجموع وتوزيعه حسب النوع.
  - **الملخص**: الإيرادات والمصروفات والرصيد الصافي لكل شهر وللسنة.
- **وثائق PDF للطباعة**: كشف نتائج لكل طالب (الدرجات حسب المادة، المعدل والتقدير، الحفظ، الحضور، خانات التوقيع)، وشهادة تقدير بالحفظ أو شهادة ختم القرآن الكريم.
- **واجهة أسهل**: أزرار اختصار في الرئيسية (تسجيل الحضور، تسميع جديد، إضافة طالب، إدخال درجات، المالية، إعلان)، وصور رمزية للطلاب.
- **حلقات المعلمين**: تحدد الإدارة الحلقات التي يدرّسها كل معلم، فلا يرى إلا طلاب حلقاته وحضورهم وتسميعهم.
- **التصدير إلى Excel** (للإدارة، أيقونة التنزيل أعلى الشاشة): قائمة الطلاب، ملخص الحضور الشهري، الرسوم، والدرجات بصيغة CSV.
- **الحسابات** (للإدارة، من أيقونة أعلى الشاشة): تحديد صفة كل مستخدم (معلم، ولي أمر، طالب) وربط أولياء الأمور بملفات أبنائهم.
- **العمل دون إنترنت**: تُحفظ التغييرات محليًا وتتم مزامنتها تلقائيًا عند عودة الاتصال.

## التشغيل

1. افتح المجلد في Android Studio.
2. انتظر اكتمال Gradle Sync.
3. شغّل التطبيق على هاتف Android أو محاكي.
4. أنشئ حساب الإدارة من شاشة «إنشاء حساب» بالبريد `sidibey487@gmail.com`.

يُبنى ملف APK تلقائيًا عبر GitHub Actions عند كل دفع إلى `main` (ويمكن تنزيله من صفحة Actions).

## الصلاحيات

- **الإدارة**: كامل الصلاحيات، بما فيها الحذف وإدارة الحسابات.
- **المعلم**: إضافة الطلاب وتعديلهم، وتسجيل الحضور والتسميع.
- **ولي الأمر والطالب**: الاطلاع فقط على ملفات الطلاب المرتبطة بالحساب (حفظًا وحضورًا).

كل حساب جديد يُنشأ بصفة «طالب» دون ربط؛ تقوم الإدارة من تبويب «الحسابات» بتغيير الصفة وربط الحساب.

قبل الاستخدام الفعلي، انشر ملف `firestore.rules` في Firebase Console (أو `firebase deploy --only firestore:rules`).
